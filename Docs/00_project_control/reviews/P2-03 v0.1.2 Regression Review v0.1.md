## 4. Root Cause

実Production Carrierでは、

```text
Excel Date Cell
↓
.Value2
↓
Numeric Excel Date Serial
```

となる。

P2-03はこのCarrier Contractを既に考慮しており、

```text
VBA Date
+
Excel numeric Date Serial
```

を有効Dateとして扱う。

一方、P2-02 v0.1.2の新しいDetection History Validationは、

```text
IsDate(firstDetectedAtValue)
IsDate(lastDetectedAtValue)
```

によってInitialized Metadataを検証している。

この判定では実Pipelineから渡されるExcel numeric Date Serialを正しく許容できず、

```text
Valid Initialized Metadata
↓
ConfigurationError
```

となっている。
