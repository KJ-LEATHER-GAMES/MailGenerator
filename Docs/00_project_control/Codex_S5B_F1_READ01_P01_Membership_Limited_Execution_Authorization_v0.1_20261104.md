# S5-B F1-READ-01：P01所属メンバーの限定実行承認

S5B-TestPC-01上で、次のWindows標準コマンドを通常権限で1回だけ実行することを承認します。

`net localgroup "CodexSandboxUsers"`

**承認範囲**

- 指定コマンド1回のRead-only実行のみ
- 追加オプション、追加コマンド、再試行なし
- 管理者昇格、設定変更、ファイル作成なし
- エラー・アクセス拒否時は停止
- 実ユーザー名・SID・ホスト名は報告せず、匿名IDへ変換
- 直接メンバーと推移的所属を区別する

結果は`CODEX_OBSERVED`として記録し、主体区分・匿名メンバー情報・未確認事項を報告してください。

専用ユーザー作成、所属変更、ACL変更、Excel操作、Preflight実行は承認しません。

F1Read01DecisionとC1OverallAssessmentは、実行結果を評価してから更新してください。

報告後、停止してください。
