# S1-B Backup Precheck（Read-only）

Primary Archiveの空3階層は作成済みで、NTFS ACLの確認も完了しています。

Primary Directoryの残留リスクについては、ユーザーによる正式受容状態を確認し、未承認ならそのまま記録してください。

今回指定するBackup媒体・保存先について、以下を読み取り専用で確認してください。

- Primaryとは別の物理ディスクであること
- ファイルシステム、暗号化方式と有効状態
- アクセス権限・共有範囲
- 保存先の存在、空き容量、既存ファイルとの衝突
- Backup作成後の復元試験に必要な条件

確認不能な事項は`UNKNOWN`として報告してください。

今回もファイル作成・コピー・ACL変更・暗号化設定変更・管理者昇格・Git操作は禁止です。

個人ユーザーパスを含むローカルGit履歴のPush禁止は継続します。

結果をMarkdownで報告し、原本コピーや`EXECUTE_ARCHIVE`へ進まず停止してください。
