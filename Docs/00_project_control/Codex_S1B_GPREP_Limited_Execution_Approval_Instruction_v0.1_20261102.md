# S1-B G-PREP 限定実行承認指示

以下の作業について、**G-PREPに限定して実行を承認します。**

承認範囲：

- 指定したRepository外の非公開退避先における新規Runフォルダの作成
- USBルートの変更前情報（Root Snapshot）の新規保存
- 保存内容の読み戻しとSHA-256照合
- SVI Snapshot取得に必要なユーザー向け手順の提示

承認しない作業：

- USBルートおよびSVIのACL変更
- Stage 1／Stage 2の実行
- SVI Snapshotの管理者権限による代理取得
- Evidence原本のコピー
- Git操作
- その他の設定変更

前回の「S1-B G-PREP 永続退避準備」指示書に従って実施してください。

退避先の適合性、USB媒体の同一性、SIDの整合性を確認できない場合は、ファイルを作成せず停止してください。

G-PREPの結果を報告したら停止し、次の承認を待ってください。
