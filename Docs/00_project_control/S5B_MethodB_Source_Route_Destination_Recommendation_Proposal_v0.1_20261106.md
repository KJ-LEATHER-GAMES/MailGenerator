# S5-B 方式B：搬入元・搬入経路・搬入先の推奨案

結論：方式Bの中でも「B-L：同一PC内の管理主体によるローカル事前搬入」を第一候補として推奨します。

理由は、既存の`E-P204-WB`を活用し、新たなUSB媒体やネットワーク転送を増やさず、Archiveと検証用コピーのアクセス境界を分離できる可能性があるためです。

ただし、正規Primaryが検証PCと同じ物理PC上にあることは未確認です。そのため、現段階ではB-Lを設計上の第一候補とし、実行経路の確定とは区別します。

## 1. 3点の推奨構成

| 判断項目 | 推奨案 | 判断理由 |
| --- | --- | --- |
| 搬入元 | `E-P204-WB`の正規Primary | 保全・復元照合のEvidenceがある。BackupやOneDrive上の別コピーを自動採用しない |
| 搬入経路 | B-L：認可済み管理主体による同一PC内のローカルコピー | 新規媒体・クラウド・同期・ネットワーク搬送を回避できる。ただし同一PCであることが成立条件 |
| 搬入先 | 検証PCの管理主体専用ローカル`STAGE`領域 | 専用標準ユーザーC1からのアクセスを遮断し、後から実行用`WORK`コピーだけを引き渡す |

搬入主体は、既存Primaryへの読取り権限を持ち、後続の個別承認で指定される管理側の操作主体とします。管理者権限を持つことと、コピー操作が承認されていることは別です。

## 2. 搬入先の具体的な配置案

新しい`C:\S5B_Preflight\`を作るのではなく、Windowsユーザーごとのローカルプロファイルを利用する配置を優先します。

| 論理領域 | 配置候補 | アクセス方針 |
| --- | --- | --- |
| `STAGE` | 管理主体のローカルプロファイル内の`S5B\STAGE` | 管理主体のみ。C1からのアクセス拒否を後続Gateで実証 |
| `WORK` | 将来作成するC1標準ユーザーのローカルプロファイル内の`S5B\WORK` | C1のCompile対象コピーを配置 |
| `EVIDENCE` | 管理主体が管理する独立したPrivate記録領域 | 記録担当・保持方針・非同期性を別途固定 |

すべて未作成の候補です。ローカルプロファイル配下でも非同期・非共有・適切なACLが成立していると推定せず、実行前に限定確認します。

特に、共通の`C:\ProgramData`や`C:\`直下へ安易に新規フォルダーを設けるより、管理主体とC1の領域を論理的に分離しやすい構成を優先します。ただし、後続のアクセス実測により成立を判定します。

## 3. 推奨する受渡しの流れ

| 段階・操作 | 位置付け・条件 |
| --- | --- |
| 正規Primary：E-P204-WB | 保全済み原本・変更禁止 |
| B-L成立確認後、個別承認で読み取り・コピー | |
| 管理主体のSTAGE | コピーSHA確認・原本とは別の管理領域 |
| A＋C1構築 → 隔離実測 → 安全Fixture PASS | |
| C1標準ユーザーのWORK | 別承認で引渡し・SHA再照合 |
| S5-B Compile | AUTH-06個別承認後のみ実行 |

この順序なら、管理主体による事前搬入と、隔離済みユーザーへの本番コピー引渡しを独立したGateにできます。

## 4. B-Lが成立しなかった場合

既存EvidenceからPrimaryと検証PCの同一性を確認できなければ、B-Lは`ROUTE_UNVERIFIED`で停止します。

その場合の第二候補は、B-M：専用の認可済みオフライン搬送媒体です。

既存のS1 Backup媒体は保全用として維持し、搬送用途に無断転用しません。B-Mを選ぶ場合も、媒体の用意、転送中の保護、中継コピーの保持・削除方針について別承認が必要です。

重要なのは、B-Lが未成立という理由だけで、自動的にB-Mの実行を許可しないことです。

## 5. B0の机上判定

| 項目 | 現時点の判定 |
| --- | --- |
| 搬入元の論理Artifact | `SELECTED：E-P204-WB PRIMARY` |
| 搬入主体の役割 | `DEFINED：AUTHORIZED ARCHIVE OPERATOR` |
| 第一候補の搬入経路 | `B-L / PROPOSED` |
| 同一PCの物理配置 | `UNKNOWN` |
| 管理側STAGE・C1側WORK配置方式 | `PROPOSED` |
| A＋C1正式選定 | `NOT_GRANTED` |
| B0正式完了 | `PENDING_PHYSICAL_ROUTE_CONFIRMATION` |
| コピー作成・PC変更 | `NOT_GRANTED` |

次に必要な情報は1点だけです。

`E-P204-WB`の正規Primaryが、検証PC`S5B-TestPC-01`と同じ物理PC上にあることを、既存Private Indexまたは既存管理記録から確認できるか。

これが確認できればB-Lを正式候補として固定できます。確認不能なら、再び広範なPC調査を行わず、B-Mの追加負担と安全性を判断します。

今回は机上提案のみです。既存の方式B設計書v0.2 DRAFT、Repository、PC、Archiveには変更を加えていません。

## まとめ

搬入元は`E-P204-WB`の正規Primary、経路は同一PC内ローカルコピー（B-L）、搬入先は管理主体専用STAGEを第一候補として推奨します。同一PCの確認が残るため、B0はまだ正式完了ではありません。コピーや環境変更は未承認です。
