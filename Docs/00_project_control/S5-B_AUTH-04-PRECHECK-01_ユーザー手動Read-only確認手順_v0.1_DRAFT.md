1. **既に参照できる既存Private Index**を、通常の閲覧可能な方法で開く。閲覧にクラウドからの新規取得、外部アクセス、権限昇格、編集操作が必要なら開かずSTOPする。Private Indexを開く操作は承認対象だが、Archive原本を開く操作は含まない。

3. 次の**分類に必要な情報のみ**読み取る。
   - `Primary` が保全されているPC／保管媒体の**役割**（例：検証PC上／別PC／取外し媒体／不明）。実ホスト名は報告しない。

## 2. STEP B — WorkspaceCandidate（候補フォルダーの存在・属性を見るだけ）

**候補**：`C:\S5B_Preflight\`。これは既存計画上の候補であり、作成済みとは限らない。検証PCでの通常GUI閲覧に限定。

### 画面操作（Windows 11）

1. エクスプローラーを既存の通常権限で開く（タスクバーのアイコン、または `Windows`+`E`）。**管理者として起動しない**。Microsoftの通常UI操作に従う。
2. 左側の**「このPC」→「ローカル ディスク (C:)」**を選択し、Cドライブ直下の表示から **`S5B_Preflight`という名前のフォルダーが見えるかだけ**を確認する。検索、コマンド入力、保護領域の列挙、フォルダー内部のOpenはしない。
3. **通常の一覧に存在しない場合**：`WorkspaceCandidate: NOT_FOUND` と記録。ただし、非表示・権限制限などで「見えないだけ」の疑いがあれば`UNKNOWN`とする。**新しいフォルダーを作らず、表示設定も変更せず**、このSTEPの残りはスキップしてSTEP Cへ。`NOT_FOUND`はA＋C1不成立という意味ではない。
4. **存在する場合**：フォルダーを**開かずに**右クリック→**「プロパティ」**を選択する。Windows 11で項目が見えない場合は、右クリックメニューの**「その他のオプションを表示」**から探す。適用・変更系の操作はしない。
5. プロパティの**「全般」**で、表示されるフォルダー種別と場所だけを見る。ショートカットや意図しない別ドライブ参照など、名称と実体の関係が曖昧なら `UNKNOWN` とする。隠しファイル表示やフォルダーオプションは変更しない。
6. 表示される場合だけ **「共有」**タブを閲覧し、共有設定に関する表示を必要範囲で確認する。**「共有…」「詳細な共有」「アクセス許可」等の設定操作はしない**。共有表示がない・読めない場合は `UNKNOWN` の補足とする。共有タブ上の非共有表示だけで全ての間接共有が無いとは認定しない。
7. 表示される場合だけ **「セキュリティ」**タブを閲覧する。**許可・拒否の詳細リストを転記せず**、ユーザー専用作業領域として使えることを既存情報だけで証明できるかを判断する。**「編集」「詳細設定」「続行」「変更」等には進まない**。将来のC1ユーザーの実効アクセスをここからPASS認定しない。
8. 必要で、既存の承認範囲内で閲覧可能な場合に限り、**親の`C:\`自体のプロパティ**を同様に確認する。ドライブ配下の探索や他フォルダーのACL検査へ広げない。
9. 閉じるときは、変更項目がないことを確認して通常の閉じ方を使用。UAC・管理者要求・変更確認が現れたらSTOP。

## 3. STEP C — NetworkIsolationMethod（接続状況を読むだけ）

### 画面操作（Windows 11）

1. **「スタート」→「設定」→「ネットワークとインターネット」**を開く。`Windows`+`I` →「ネットワークとインターネット」でも可。**接続の修復・トラブルシューティングは起動しない。**
2. 画面上部の接続状態と、表示される**「Wi-Fi」「イーサネット」**の現状を閲覧する。必要なら該当項目の**状態・説明を表示する画面だけ**に入ってよい。SSID、IP、MAC、端末名、接続先名は記録・共有しない。
3. 既存の画面と自身の把握している接続構成から、将来オフライン化する際に**何を止め、どの順で元へ戻す必要があるか**、方法を机上で表現できるかを判断する。
   - **Wi-Fiだけ**が確認できる場合：将来はWi-Fi通信の切断・復旧方法の設計候補となる。**今回はWi-Fiのスイッチを触らない**。
   - **イーサネットだけ**が確認できる場合：将来は有線接続の切離し・復旧方法の設計候補となる。**今回はケーブルに触らない**。
   - **両方**、VPN、モバイル回線、USBテザリング、ドック経由、仮想アダプター等が把握されている場合：それらも将来の隔離の設計対象。確認できない経路が残れば`REVIEW_REQUIRED`／`UNKNOWN`。**新たなネットワーク探索には進まない**。
4. 既存セッションがネットワーク・リモート接続に依存しているかが不明な場合は、復旧・作業継続性のリスクとして`REVIEW_REQUIRED`。今切断して確認しない。
5. **押さない・変更しない項目**：Wi-Fiオン／オフ、機内モード、接続・切断、VPN切断、イーサネット設定、ネットワークアダプター無効化、プロキシ、Firewall、同期アプリの一時停止、再接続、トラブルシューティング、更新・診断・リセット。

### 判定（厳密に）

| 出力 | 条件 | 意味しないもの |
|---|---|---|
| `DESIGNABLE` | 既存の通常GUI観察と既知構成だけで、後続承認時の**通信制限方法と復旧手順を机上設計できる** | PCがオフライン、安全に隔離された、全通信経路を遮断できた、Officeが利用可能という証明ではない |
| `REVIEW_REQUIRED` | 複数の接続方式、リモート依存、復旧条件、追加の既知通信経路など、方法を決める前に具体的な判断が必要 | `FAIL`／オフライン不可を意味しない |
| `UNKNOWN` | 表示が得られず、既知情報だけでは通信条件を分類できない | 存在しない接続経路を推測する |

**報告用の根拠例**：`「設定画面ではWi-Fi接続を確認。有線・その他接続の利用は把握していない。将来の切断／復旧方法は机上設計可能、実施なし」`、`「Wi-Fiと有線を同時に使用。双方の戻し方が未確定のため要レビュー」`。

## 4. STOP条件と対応

**以下の事象は、その場で操作をやめ、そこで止める**。該当セクションの分類が不明なら`UNKNOWN`とする。許可されていない別の方法で取り直さない。

- PC識別が不明、対象と別のPCである疑い、アクセスできないPrivate Indexの追加探索が必要。
- 管理者認証／UAC／`続行`要求、アカウント切替、権限変更が必要。
- Private Indexの参照時にダウンロード、外部接続、クラウド同期、新規アプリ、編集・保存を求められる。
- Workbook、Primary/Backup、Clone、ZIP、フォルダー内部の保護対象コンテンツを開かないと進めない。
- ファイル・フォルダー作成／コピー／移動／削除、ハッシュ測定、スクリプト／CMD／PowerShell実行が必要。
- Wi-Fi等の切断／再接続、同期アプリ操作、ネットワーク・Firewall・Officeの設定変更が必要。
- 意図しない画面や機微情報が露出し、これ以上の閲覧が不要または不適切。

**存在しない候補フォルダーや、記録不足による`UNKNOWN`はSTOP対象そのものではない**。該当項目を`NOT_FOUND`／`UNKNOWN`として、他の承認済み項目へ進める。**予期しない変更要求・権限要求・対象外アクセス**は全体STOPとする。無断の再試行・回避策は禁止。
