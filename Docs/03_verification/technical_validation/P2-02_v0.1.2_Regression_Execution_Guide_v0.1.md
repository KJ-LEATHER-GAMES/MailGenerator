## v0.1.2 Expected Production Behavior

```text
Detection History:
First Blank + Last Blank
-> Uninitialized

First Date + Last Date
-> Initialized

First Blank + Last Date
or
First Date + Last Blank
-> Invalid / Partial -> Failure

Non-blank non-date First / Last
-> Invalid -> Failure
```

```text
Existing + Uninitialized
-> TemplateLocation = Current
-> Status = Active
-> FirstDetectedAt = SyncTimestamp
-> LastDetectedAt = SyncTimestamp
```

```text
Reactivated + Uninitialized
-> TemplateLocation = Current
-> Status = Active
-> FirstDetectedAt = SyncTimestamp
-> LastDetectedAt = SyncTimestamp
```

```text
Unused + Uninitialized
-> TemplateLocation = Existing
-> Status = Unused
-> FirstDetectedAt = Blank
-> LastDetectedAt = Blank
```

```text
Already-Unused + Uninitialized
-> No-op
```

`TemplateLocation` does not determine Detection History initialization state.
Empty TemplateLocation is accepted as a compatibility input.
Non-empty TemplateLocation must still be Subject / Body / Both.
